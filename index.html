Готовый УПД для СБИС

Один раз загрузите прошлый УПД, выгруженный из СБИС в Excel: приложение возьмёт из него реквизиты и названия товаров. Потом каждый раз нажимайте «Скачать УПД» и загружайте файл в СБИС.

Порядок работы: сканируете ШК короба (наклейка WB на коробе), затем КИЗ всех товаров в этом коробе. Для следующего короба сканируете его ШК и продолжаете.

Баркод WB (например 2058557408143) может не совпадать с GTIN в КИЗ. Для каждого товара один раз отсканируйте баркод с этикетки, затем его КИЗ: приложение запомнит пару и дальше будет подставлять баркод само. Если сканировать баркод перед каждым КИЗ, приложение ещё и проверит, что КИЗ от этого товара.

Артикулы подтягиваются из ваших FBS-сборок, а баркоды и артикулы разом — из выгрузки карточек WB (кнопка «Загрузить карточки WB»).

Порядок работы: сканируете стикер заказа, строка подсвечивается жёлтым, затем сканируете КИЗ (Data Matrix «Честного знака»). Код записывается в эту строку, и можно сканировать следующий стикер.

Если сканер не читает стикер, введите цифры под штрихкодом (хватит последних 4–5) и нажмите Enter. Можно также просто нажать на строку.

На телефоне нажмите «Камера» и наводите камеру по очереди: стикер заказа, затем Data Matrix на товаре. Камера остаётся открытой, можно идти по всем заказам подряд.

Прогресс хранится в этом браузере, поэтому после случайной перезагрузки страницы работа не потеряется.
