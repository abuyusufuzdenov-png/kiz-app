# КИЗ Сканер

Веб-приложение для сборки FBS-заказов Wildberries: сканируете стикер заказа (сканером или камерой телефона), затем Data Matrix «Честного знака» — КИЗ записывается в шаблон sgtin из кабинета WB. Готовый файл скачивается для загрузки обратно в WB, коды по артикулам выгружаются для УПД в СБИС.

Все данные обрабатываются только на устройстве, никуда не отправляются.
